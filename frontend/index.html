💎 Palabras bonus

Además de las palabras principales existen palabras bonus.

  • Otorgan puntos extra.
  • No cuentan para completar el desafío diario.
  • No cuentan para desbloquear pistas.
  • Pueden seguir descubriéndose incluso cuando una casilla se vuelve gris.

🏆 Ranking

El ranking puede ordenarse por:

  • Puntaje
  • Puntaje + bonus
  • Cantidad de palabras
  • Palabras + bonus

Activa la opción «Incluir bonus» para sumar los puntos y las palabras bonus.
